**要旨**：佛在舍卫国东园鹿母讲堂敷座，一比丘连发八问，佛一一解答：（1）五受阴以「欲」为根、欲集、欲生、欲触；（2）「非五阴即受，亦非五阴异受，能于彼有欲贪者是五受阴」；（3）思惟未来得如是五蕴，名「阴阴相关」；（4）十一分别总说名「阴」；（5）色阴以四大为因缘，受想行阴以触为因缘，识阴以名色为因缘；（6）味、患、离之定义；（7）于五蕴见我、异我、相在而生我慢，不见则无我慢；（8）观十一分别非我、不异我、不相在，疾得漏尽。时会中有钝根比丘生邪念：「若无我者，作无我业，于未来世谁当受报？」佛知其念，以「无常 → 苦 → 变易法 → 非我、非我所（正见） → 厌 → 离欲 → 解脱」破斥其疑，众多比丘不起诸漏，心得解脱。

**八问答一览**

| 次序 | 比丘所问 | 世尊解答要点 |
|---|---|---|
| 一 | 五受阴以何为根、集、生、触？ | 欲为根，欲集、欲生、欲触 |
| 二 | 五阴即受，为五阴异受？ | 非即非异；能于彼有欲贪者，是五受阴 |
| 三 | 有二阴相关耶？ | 思惟「我于未来得如是五蕴」，名阴阴相关 |
| 四 | 云何名阴？ | 十一分别一切总说名阴 |
| 五 | 何因何缘名五阴？ | 色以四大为因缘；受想行以触为因缘；识以名色为因缘 |
| 六 | 云何味、患、离？ | 喜乐是味；无常苦变易是患；调伏、断、越欲贪是离 |
| 七 | 云何生我慢／无我慢？ | 见我、异我、相在生我慢；不见则无我慢 |
| 八 | 何所知见疾得漏尽？ | 观十一分别非我、不异我、不相在 |
