**要旨**：佛在拘萨罗国萨罗聚落村北申恕林住，聚落主大姓婆罗门闻佛十号功德，严驾来诣，问佛「何论何说」。佛答「我论因、说因」——即「有因有缘集世间，有因有缘灭世间」：凡夫不如实知五蕴之集、灭、味、患、离，故爱乐、赞叹、染著心住 → 取 → 有 → 生 → 老死忧悲恼苦（世间集）；圣弟子如实知故不爱乐、不留住 → 爱灭 → 取灭 → 有灭 → 生灭 → 老死忧悲恼苦灭（世间灭）。

**次第**
- 有因有缘集世间：不如实知五蕴集、灭、味、患、离 → 爱乐、赞叹、染著 → 取 → 有 → 生 → 老死忧悲恼苦
- 有因有缘灭世间：如实知五蕴集、灭、味、患、离 → 不爱乐、不留住 → 爱灭 → 取灭 → 有灭 → 生灭 → 老死忧悲恼苦灭
