# 字段说明

## data/terms.csv
名相、巴利、对等程度、所属相应、状态

## data/relations.csv
起点、终点、关系类型（六种之一）、备注

## data/sutras.csv
由 `pipeline/01_split.py` 生成。其中「所属诵」「会编号」为人工填写，重跑脚本不会覆盖。
- 经号：大正藏 T99 经号，格式 `T99-0001`（唯一 ID）。合并区块写成范围，如 `T99-0140~0141`
- 顺序：该经在 CBETA 文件中的实际位置（1–1355）。T99-0455 在文件中排错了位置，顺序号与经号不同步
- 卷：该经起始所在的卷（1–50）
- 所属诵：五阴诵 / 六入处诵 / 杂因诵 / 道品诵（人工填，来源待核）
- 字数：正文字数（含标点，不含换行）
- 会编号：印顺《杂阿含经论会编》对应编号（人工填，可留空）
- 备注：合并区块 / 略出（不足 30 字，疑为前经省略）/ 顺序错位

## data/tags.csv
经号、名相、角色（主题/定义/提及）、置信度（高/中/低）、来源（AI/人工）、状态（待核/已核）

## data/mapping/会编对照.csv
大正藏经号与《会编》编号的对照

## data/mapping/巴利对应.csv
大正藏经号与《相应部》经号的对照，含对应程度
