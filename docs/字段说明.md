# 字段说明

## data/terms.csv
名相、巴利、对等程度、所属相应、状态

## data/relations.csv
起点、终点、关系类型（六种之一）、备注

## data/sutras.csv
- 经号：大正藏 T99 的经号（唯一 ID）
- 所属诵：五阴诵 / 六入处诵 / 杂因诵 / 道品诵
- 字数
- 会编号：印顺《杂阿含经论会编》对应编号（暂可留空）

## data/tags.csv
经号、名相、角色（主题/定义/提及）、置信度（高/中/低）、来源（AI/人工）、状态（待核/已核）

## data/mapping/会编对照.csv
大正藏经号与《会编》编号的对照

## data/mapping/巴利对应.csv
大正藏经号与《相应部》经号的对照，含对应程度
