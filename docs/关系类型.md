# 关系类型

名相之间只用以下六种关系。每条边必须归入其一；归不进去，说明关系本身还没想清楚。

| 关系 | 语义 | 方向 | 例 |
|---|---|---|---|
| 开合 | 同一法的粗细分法，总摄别 | 单向（总→别） | 五蕴 → 色蕴 |
| 缘起序 | 有次第的依待关系 | 单向（前支→后支） | 触 → 受 |
| 异译同实 | 同一所指的不同译语 | 双向 | 五阴 ↔ 五蕴 |
| 巴利对应 | 与巴利术语的对应 | 双向 | 受蕴 ↔ vedanākkhandha |
| 修证 | 观法 → 所断 → 所证 | 单向 | 无我观 → 断我见 |
| 部派歧义 | 同名而用法分歧处 | 双向 | 逐例标注 |

## 对等程度（巴利对应必填）

- 严格：两者所指完全一致
- 大致：主要义项一致，有细微差别
- 存疑：对应关系尚未核实

## 两条原则

- 论书（部派佛教及以后）的诠释框架进入图谱时，必须明确标注为后期诠释，不与经文层混用。
- 同字异指的术语分立为不同节点（例如行蕴之「行」与缘起支之「行」）。
