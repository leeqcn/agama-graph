# 标注规范（草案，试标后修订）

每条标签是「一条经 — 一个名相」的关系，记录在 `data/tags.csv`。

## 角色

- 主题：这条经的核心内容就是讲这个名相。每条经通常 1–3 个。
- 定义：这条经在解释这个名相是什么（给出定义或分类）。
- 提及：经文中出现，但不是讲述重点。

## 置信度

- 高：经文明确，几乎无歧义
- 中：合理但可能有别的读法
- 低：不确定，需人工复核

## 来源与状态

- 来源：AI（模型标注）或 人工
- 状态：待核 或 已核。AI 标注一律从「待核」开始，由人工复核后改为「已核」。

## 规则

1. 名相只能从 `data/terms.csv` 的词表中选，不得自创。
2. 找不到合适名相时，不勉强挂靠；在备注中记下，供补词表时参考。
3. 「提及」类标签数量不设上限，但不要把泛泛出现的词（如无常）全部标上。
