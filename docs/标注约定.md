# 标注约定

经文的标签先由我自己读经时随手标注，之后再整理。记录在 `data/tags_raw.csv`，一条经一行，五列：

| 列 | 内容 |
|---|---|
| 经号 | 如 T99-0001 |
| 标签（unsorted） | 想到的全部标签，含地点、人物，顺序随意 |
| 标签 | 入选的标签，按数字编号排序（有论证次第的，按经文中的次第编号） |
| 核心 | 最重要的至多三个，按 A、B、C 的顺序 |
| 备注 | 随手笔记 |

## 写法

- 一个格子里有多个标签，**一行一个**。标签内部可以带顿号（如「生、老、病、死怖」）。
- 标签尽量照经文用词写，近义词先不合并（如喜贪与欲贪）。
- 未整理的标签以后统一整理，不需要现在判断对错。

## 日后整理（计划）

1. 建一张映射表：原始标签 → 标准名称 + 类别。世尊、佛等同义写法指向同一个标准名称，原写法保留为异称。
2. 类别：名相、地点、人物，其余放「其他」或附录。网页上不同类别用不同颜色显示。
3. 标准名称之间建立层级和关系，如五蕴下有色、受、想、行、识。
4. 「标签」栏里的编号次第，可作为修证次第等关系的依据。
