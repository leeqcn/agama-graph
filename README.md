# 阿含名相图谱

以《杂阿含经》为主线的佛学名相图谱：把每一条经文打上名相标签，每个名相配有定义与对应经文，并梳理名相之间的关系。

> 状态：搭建中。目前完成目录骨架，下一步是经文切分。

## 目录结构

- `data/`　CSV 主数据（名相、关系、经文、标签、对照表）
- `definitions/`　名相定义，一个名相一个文件，人工撰写
- `pipeline/`　切分与标注脚本
- `pages/`　网站页面，MkDocs 读取这里
- `docs/`　规范文档（关系类型、标注规范、字段说明）
- `raw/`　CBETA 原始文件，不提交（见 `raw/README.md`）

## 数据来源

经文底本：CBETA 电子佛典集成（中华电子佛典协会，https://www.cbeta.org），大正藏 T99《杂阿含经》。
署名格式请对照 CBETA 官方要求，确认后在此补全。
