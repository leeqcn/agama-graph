# 阿含名相图谱

个人学习《杂阿含经》的笔记：把经文逐条切分，记下自己读经时的标签，日后整理成名相、定义和名相之间的关系图。

> **说明**：本项目仅供个人学习使用，**不保证内容正确**。标签、整理和说明都是个人理解，难免有误；经文请以 CBETA 及原典为准，引用前务请自行核对。

> 状态：搭建中。已完成经文切分和网站页面，目前在逐条标注阶段。

## 致谢

衷心感谢中华电子佛典协会（CBETA）。本项目的全部经文都来自 CBETA 多年的电子化与校对工作，并承蒙其开放使用。

## 目录结构

- `data/`　数据：`sutras.csv`（经文清单）、`tags_raw.csv`（我的标签，逐条填写）、`T99_teiHeader.xml`（CBETA 文件头）；`terms.csv` 等名相数据待标签整理后再建
- `definitions/`　名相定义（日后手写）
- `pipeline/`　脚本：`01_split.py` 切分经文，`04_build.py` 生成网页
- `pages/`　网站页面（MkDocs 读取这里，由脚本生成）
- `docs/`　规范文档
- `raw/`　CBETA 原始文件，不提交（见 `raw/README.md`）

## 更新网站

```
python3 pipeline/04_build.py
```

填完标签后运行一次，提交 `data/tags_raw.csv` 和 `pages/`，推送后网站自动更新。
